# ブロック崩しとPython

情報処理Ⅱの学習用ゲームです。

https://YakabiKiyoshi.github.io/info2-breakout/

スマホは画面をなぞるか左右ボタンを長押しして移動し、開始・発射ボタンで遊びます。インストール・ログインは不要です。初回読み込みと再読み込みにはインターネット接続が必要です。

ゲーム内の「Pythonを読む」で授業に対応するコードを確認できます。プレイ記録はブラウザ内に保存され、CSVでダウンロードできます。

画像・効果音: Kenney Puzzle Pack 1 / Interface Sounds (CC0)。Python実行環境: Pyodide 0.27.7。
